# 潮间带生态修复

放置牡蛎礁、海草床和围护桩，推进潮汐周期并争取更高生态评分。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认自动打开浏览器）
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

开发服务器默认地址：http://localhost:5173

## 游戏玩法

- **牡蛎礁**（12预算）：提升水质，有几率净化自身污染
- **海草床**（10预算）：提升生物多样性和幼体数量
- **围护桩**（8预算）：减缓污染扩散速度，保护周边区域
- 每回合获得 8 预算，污染会向四周扩散
- 风暴潮可能损毁设施，请合理布局

## 场景

- **入门滩涂**：低难度，适合新手熟悉流程
- **污染湾口**：高难度，污染密集且预算紧张
- **风暴前线**：中难度，风暴频发考验恢复能力
- **沙盒编辑器**：自由配置地图和参数，打造专属挑战

## 项目结构

```

├── renderer/
│   └── board.js         # 棋盘与UI渲染
├── editor/
│   └── sandbox.js       # 沙盒编辑器逻辑
├── ui/
│   └── modals.js        # 弹窗与交互控制
├── styles/
│   └── main.css         # 主样式文件
└── main.js              # 入口文件，整合所有模块
```

## 扩展指南

### 新增场景

在 `src/data/scenes.js` 的 `scenes` 对象中添加新场景配置即可。

### 新增设施类型

1. 在 `src/game/constants.js` 中添加成本和图标
2. 在 `src/game/state.js` 中实现设施效果
3. 在 HTML 中添加对应工具按钮

### 修改游戏规则

所有游戏数值参数集中在 `src/game/constants.js`，可直接调整平衡性。
